# Governance

`4alvit` is the primary maintainer of this unofficial DESLOC Home Assistant
integration. The maintainer owns review and merge decisions, releases,
dependency updates, private security reports and conduct enforcement.
Contributors propose changes through public issues and pull requests and supply
sanitized evidence, automated regressions and updated documentation.

Technical decisions are discussed in the relevant issue or pull request. The
maintainer resolves disagreements using the documented scope, security impact,
protocol evidence and maintenance cost. Contributors can request reconsideration
with new evidence in the same discussion. Private security and conduct details
use [SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Required checks and independent review must pass before normal GitHub merging.
Automation assists review; it does not replace maintainer accountability.
A source merge does not authorize operating a physical lock or prove device
compatibility. Release acceptance follows [RELEASING.md](RELEASING.md).

Recognitions such as an OpenSSF badge are linked from README within 48 hours of
receipt and corrected when evidence changes. No badge is claimed before the
project's own assessment is verified.

## Continuity limitation

There is no designated backup maintainer or tested mechanism to restore
repository, CI and release access within one week if the primary maintainer is
unavailable. Bots and hypothetical account recovery are not substitutes.
OpenSSF access continuity and bus-factor requirements remain unmet.
