# Diagram sources

These SVG files are editable source assets, not screenshots. They use a
720-pixel viewBox, system fonts, explicit text labels, and a vertical layout
for GitHub README rendering. Click a diagram to open it at full size.

Each image includes an accessible title and description. The surrounding
English guides explain the same process in text. Keep the SVGs self-contained:
no scripts, external fonts, remote images, or embedded HTML.

After editing, parse the SVG as XML and render it in a browser. Check text and
arrow placement at full size and in a 375-pixel viewport. Keep the dark text
legible against the fixed light background; do not use color as the only label.

`release-results.svg` is a dated snapshot. Update its labels together with
[the result record](../release-results.json) and [the result guide](../release-results.md),
using evidence from the named release. Never present test counts as coverage,
physical reliability, or live project status.
